# Interaction-picture formulation

The virtual-cavity construction is exact for the selected temporal modes, but its most obvious Schrödinger-picture representation can be numerically expensive. A source cavity may empty almost completely while a receiver cavity fills almost completely, forcing both auxiliary Fock spaces to accommodate the full pulse occupation even when the physical system changes the field only weakly.

The interaction-picture construction of [Christiansen2023](@cite) removes this deterministic transfer among the virtual modes. The physical scattering remains, but the auxiliary modes are described relative to the pulse propagation that would occur without the local system.

## Mode-transfer generator

Consider ``N`` virtual modes with time-dependent couplings ``g_1(t),\ldots,g_N(t)`` in cascade order. The pure cascade terms generate a passive linear transformation of the mode operators. QuantumInputOutput writes its coefficient matrix as

```math
A_{ij}(t)=\frac12
\begin{cases}
0, & i=j,\\
g_i(t)g_j^*(t), & i<j,\\
-g_j^*(t)g_i(t), & i>j.
\end{cases}
```

Thus

```math
A^\dagger(t)=-A(t).
```

The corresponding mode transformation ``M(t)`` solves

```math
\frac{d}{dt}M(t)=A(t)M(t),
\qquad
M(t_0)=I.
```

Because ``A`` is anti-Hermitian, ``M`` is unitary. The transformed virtual-mode operators therefore obey the same bosonic commutation relations as the original ones; this is a change of representation, not an approximation.

[`coupling_matrix`](@ref) constructs ``A(t)`` and [`solve_mode_evolution`](@ref) integrates this equation.

## Transforming the full model

Let ``\boldsymbol a`` collect the virtual-mode annihilation operators. In the interaction picture their linear combinations are determined by ``M(t)``. Substituting those combinations into the full cascaded Hamiltonian and coupling operators transfers the known pulse propagation into the operator basis. The pure virtual-mode transfer Hamiltonian is then absent from the residual dynamics, while interactions involving the physical system remain.

This separation is useful only when the removed transfer is large compared with the field redistribution generated by the system. In that regime, the transformed virtual modes remain close to their initial occupations and substantially smaller Fock cutoffs can be sufficient. The representation does not change the exact selected-mode model; numerical savings come from choosing a basis adapted to its dominant motion.

## Symmetric two-mode case

For one source and one receiver targeting the same normalized envelope ``u(t)``, define the accumulated pulse norm

```math
F(t)=\int_{t_0}^{t}dt'\,|u(t')|^2.
```

The mode rotation can be parameterized by

```math
\sin^2\theta(t)=F(t),
```

which gives

```math
M(t)=
\begin{bmatrix}
\cos\theta(t) & -\sin\theta(t)\\
\sin\theta(t) & \cos\theta(t)
\end{bmatrix}.
```

[`solve_mode_evolution_symmetric`](@ref) evaluates this closed form directly from the sampled envelope. At the beginning of the pulse ``M=I``; after a fully normalized pulse the source and receiver directions have been exchanged by the rotation.

## Relation to the ordinary virtual-cavity picture

The standard and interaction-picture descriptions use the same temporal-mode couplings and encode the same selected input and output modes. The difference is where the known mode transfer appears:

```text
ordinary picture:       state carries pulse transfer
interaction picture:    basis carries pulse transfer
```

The interaction picture is therefore an optional computational representation layered on top of the virtual-cavity input-output formalism, not a different physical model. The practical construction is summarized in the [Interaction picture manual](../manual/interaction_picture.md).
