# Quantum pulses and input-output theory

QuantumInputOutput combines two complementary descriptions of light: localized quantum systems are represented by discrete operators, while propagating radiation is represented by continuous-time input and output fields. The virtual-cavity construction selects a finite set of temporal modes from that continuum and promotes them to ordinary quantum subsystems [Kiilerich2019, Kiilerich2020](@cite).

## Continuous input and output fields

For Markovian bosonic channels, the input fields satisfy

```math
[b_{\mathrm{in},i}(t),b_{\mathrm{in},j}^\dagger(t')]
=\delta_{ij}\delta(t-t').
```

An SLH component ``G=(S,L,H)`` relates the incoming and outgoing fields by

```math
\boldsymbol b_{\mathrm{out}}(t)
=S\,\boldsymbol b_{\mathrm{in}}(t)+\boldsymbol L(t).
```

For a single channel with ``S=1`` and ``L=\sqrt{\gamma}\,c``, this reduces to

```math
b_{\mathrm{out}}(t)=b_{\mathrm{in}}(t)+\sqrt{\gamma}\,c(t),
```

with the conventional interaction

```math
V_{SB}(t)=i\sqrt{\gamma}\left(c\,b_{\mathrm{in}}^\dagger(t)-c^\dagger b_{\mathrm{in}}(t)\right).
```

A normalized temporal mode ``u(t)`` defines a discrete bosonic degree of freedom inside the continuum,

```math
b_u^\dagger=\int dt\,u(t)b^\dagger(t),
\qquad
\int dt\,|u(t)|^2=1.
```

The quantum state of a pulse and its temporal mode are therefore distinct pieces of information: the state lives in the Fock space of ``b_u``, while ``u(t)`` tells us how that degree of freedom is embedded in the traveling field.

## Virtual source and receiver cavities

The continuum need not be discretized in order to prepare a selected incoming mode. Introduce an auxiliary oscillator ``a_u`` upstream of the physical system and couple it to the channel with

```math
L_u(t)=g_u(t)a_u.
```

Choosing

```math
g_u(t)=
\frac{u^*(t)}{
\sqrt{1-\int_{t_0}^{t}dt'\,|u(t')|^2}}
```

causes an initial state of ``a_u`` to be emitted into the traveling mode ``u(t)``. The population lost by the auxiliary cavity is exactly the accumulated norm of the emitted wave packet [Kiilerich2019](@cite).

A selected outgoing mode can be treated in the reverse direction. A downstream auxiliary oscillator ``a_v`` with

```math
L_v(t)=g_v(t)a_v,
\qquad
g_v(t)=
-\frac{v^*(t)}{
\sqrt{\int_{t_0}^{t}dt'\,|v(t')|^2}}
```

absorbs the mode ``v(t)`` into ``a_v``. At the end of the interaction, the state of that traveling mode is therefore available as the ordinary oscillator state of the virtual receiver cavity.

The apparent endpoint singularities encode perfect emission and absorption of a normalized mode. The numerical coupling constructors regularize the sampled formulas near those endpoints; see [Pulse modes](@ref).

## SLH as the network algebra

The source cavity, physical system, passive optical elements, and receiver cavities are composed using the SLH network rules [Combes2017](@cite). An ``N``-port component is represented by

```math
G=(S,L,H),
```

where ``S`` is the channel scattering matrix, ``L`` is the vector of couplings to the traveling fields, and ``H`` is the internal Hamiltonian.

If ``G_1`` is upstream of ``G_2``, the series product used by `G₁ ▷ G₂` is

```math
G_1\triangleright G_2
=
\left(
S_2S_1,
L_2+S_2L_1,
H_1+H_2+
\frac{1}{2i}
\left[L_2^\dagger S_2L_1-L_1^\dagger S_2^\dagger L_2\right]
\right).
```

Parallel composition stacks two independent channel sets,

```math
G_1\boxplus G_2
=
\left(
\begin{bmatrix}
S_1 & 0\\
0 & S_2
\end{bmatrix},
\begin{bmatrix}
L_1\\
L_2
\end{bmatrix},
H_1+H_2
\right).
```

For feedback reduction, connect output port ``x`` to input port ``y`` of ``G=(S,L,H)``. Writing ``\bar x`` and ``\bar y`` for the retained output and input indices, respectively, the reduced model ``\widetilde G=(\widetilde S,\widetilde L,\widetilde H)`` is

```math
\widetilde S
=
S_{\bar x,\bar y}
+S_{\bar x,y}(1-S_{x,y})^{-1}S_{x,\bar y},
```

```math
\widetilde L
=
L_{\bar x}
+S_{\bar x,y}(1-S_{x,y})^{-1}L_x,
```

and

```math
\widetilde H
=
H+
\frac{1}{2i}
\left[
\left(\sum_j L_j^\dagger S_{j,y}\right)(1-S_{x,y})^{-1}L_x
-\mathrm{h.c.}
\right].
```

The coherent cross term in the series product and the additional Hamiltonian term in feedback reduction are generated by eliminating traveling-field degrees of freedom internal to the composed network. Cascade, concatenation, and feedback all preserve an SLH description, so a large network can be reduced to one final ``(S,L,H)`` triple before any master equation is solved.

The user-facing composition interface is documented in [SLH networks](@ref).

## Common SLH elements

A few standard triples are useful enough to keep as a compact reference [Combes2017](@cite). These are physical model definitions, not package-specific API contracts.

A single-port phase shifter is

```math
G_{\mathrm{PS}}
=\left(e^{i\phi},0,0\right).
```

A lossless two-port beam splitter has

```math
G_{\mathrm{BS}}
=
\left(
\begin{bmatrix}
r_{11} & t_{12}\\
-t_{21} & r_{22}
\end{bmatrix},
0,
0
\right),
\qquad
S^\dagger S=I.
```

A coherent displacement of the incoming field can be represented as

```math
G_{\mathrm{coh}}
=\left(1,\alpha(t),0\right).
```

For a one-sided cavity with annihilation operator ``a``, decay rate ``\kappa``, and detuning ``\Delta_c``,

```math
G_{\mathrm{1s}}
=\left(1,\sqrt{\kappa}\,a,\Delta_c a^\dagger a\right).
```

A two-sided cavity with rates ``\kappa_1`` and ``\kappa_2`` is

```math
G_{\mathrm{2s}}
=
\left(
I_2,
\begin{bmatrix}
\sqrt{\kappa_1}\,a\\
\sqrt{\kappa_2}\,a
\end{bmatrix},
\Delta_c a^\dagger a
\right).
```

For a two-level system coupled to two channels,

```math
G_{\mathrm{TLS}}
=
\left(
I_2,
\begin{bmatrix}
\sqrt{\kappa_g}\,\sigma_-\\
\sqrt{\kappa_\perp}\,\sigma_-
\end{bmatrix},
\frac{\omega}{2}\sigma_z
\right).
```

These elements can be cascaded, concatenated, and feedback-reduced without changing representation.

## More than one selected temporal mode

Several virtual source or receiver cavities may be introduced when the field state occupies more than one relevant temporal mode. Their couplings cannot generally be chosen independently: an upstream virtual cavity changes the field seen by downstream components, and a receiver cavity changes the field seen by later receivers.

For output mode ``v_i``, the effect of the preceding receiver cavities can be represented recursively. Starting from ``v_i^{(0)}(t)=v_i(t)``, for ``j<i`` one evolves

```math
\dot\alpha_{v_i}^{(j)}(t)
=
-g_{v_j}(t)v_i^{(j-1)}(t)
-\frac12|g_{v_j}(t)|^2\alpha_{v_i}^{(j)}(t),
```

and updates

```math
v_i^{(j)}(t)
=
v_i^{(j-1)}(t)
+g_{v_j}^*(t)\alpha_{v_i}^{(j)}(t).
```

The effective mode seen by receiver ``i`` is then

```math
v_i^{\mathrm{eff}}(t)=v_i^{(i-1)}(t).
```

For the source-cavity chain, starting from ``u_i^{(0)}(t)=u_i(t)``, the corresponding backward recursion is

```math
\dot\alpha_{u_i}^{(j)}(t)
=
-g_{u_j}(t)u_i^{(j-1)}(t)
+\frac12|g_{u_j}(t)|^2\alpha_{u_i}^{(j)}(t),
```

```math
u_i^{(j)}(t)
=
u_i^{(j-1)}(t)
-g_{u_j}^*(t)\alpha_{u_i}^{(j)}(t),
```

with

```math
u_i^{\mathrm{eff}}(t)=u_i^{(i-1)}(t).
```

The virtual-cavity couplings are then constructed from these effective modes using the same single-mode formulas,

```math
g_{u_i}^{\mathrm{eff}}(t)
=
\frac{\big(u_i^{\mathrm{eff}}(t)\big)^*}
{\sqrt{1-\int_{t_0}^{t}dt'\,|u_i^{\mathrm{eff}}(t')|^2}},
```

```math
g_{v_i}^{\mathrm{eff}}(t)
=
-\frac{\big(v_i^{\mathrm{eff}}(t)\big)^*}
{\sqrt{\int_{t_0}^{t}dt'\,|v_i^{\mathrm{eff}}(t')|^2}}.
```

This finite auxiliary evolution is the multimode extension of the virtual-cavity construction [Kiilerich2020](@cite). The backward recursion above follows the explicit two- and three-mode construction in that reference. [`effective_input_mode`](@ref) and [`effective_output_mode`](@ref) expose the corresponding numerical construction.

## Discovering output modes

The conventional first-order correlation kernel of the emitted field is

```math
g^{(1)}(t_1,t_2)
=
\langle L_s^\dagger(t_1)L_s(t_2)\rangle.
```

For a field occupying orthonormal temporal modes ``v_k``, it has the coherent-mode decomposition

```math
g^{(1)}(t_1,t_2)
=
\sum_k n_k\,v_k^*(t_1)v_k(t_2),
```

where ``n_k`` is the mean occupation of mode ``k``. `correlation_matrix` stores the transposed Hermitian kernel

```math
K(t_1,t_2)
=
g^{(1)}(t_2,t_1)
=
\langle L_s^\dagger(t_2)L_s(t_1)\rangle
=
\sum_k n_k\,v_k(t_1)v_k^*(t_2).
```

The natural temporal modes therefore satisfy

```math
\int dt_2\,K(t_1,t_2)v_k(t_2)
=n_k v_k(t_1).
```

This orientation makes the eigenvectors of the returned matrix directly proportional to the temporal mode functions ``v_k(t)`` rather than their complex conjugates.

For samples ``T_j`` with positive quadrature weights ``w_j``, let ``W=\operatorname{diag}(w_j)``. The discrete integral eigenproblem is converted to the ordinary Hermitian eigenproblem

```math
W^{1/2} K W^{1/2} y_k = n_k y_k,
\qquad
v_k = W^{-1/2} y_k.
```

Thus the eigenvalues of the weighted kernel are the mode occupations directly and the recovered samples satisfy the chosen discrete normalization. For the rectangular rule on a uniform grid, ``W=\Delta t\,I``; if ``\lambda_k`` and ``V_k`` are eigenpairs of the unweighted sampled matrix, this reduces to

```math
n_k\approx\lambda_k\Delta t,
\qquad
v_k(t_j)\approx\frac{V_{jk}}{\sqrt{\Delta t}}.
```

Other rules, including trapezoidal quadrature, use their actual weights. The practical construction is shown in [Output modes](@ref). A selected ``v_k`` can then be promoted back into the model through a virtual receiver cavity. This gives the closed workflow

```text
quantum mode in → network → continuous output → temporal-mode decomposition → quantum mode out.
```

## Finite propagation delay

A propagation delay can also be encoded by a virtual cavity instead of a spatial discretization of the field. For delays long compared with the pulse duration, capture and re-emission can occur as separated stages. Shorter delays require the delay cavity to absorb an incoming envelope while it is already emitting the delayed envelope.

Suppose the delay cavity simultaneously absorbs ``v(t)`` and emits ``u(t)``. Define

```math
D(t)=\int_{t_0}^{t}dt'\,\left(|v(t')|^2-|u(t')|^2\right).
```

Where ``D(t)>0``, the simultaneous couplings are

```math
\tilde g_{\mathrm{out}}(t)=\frac{u^*(t)}{\sqrt{D(t)}},
\qquad
\tilde g_{\mathrm{in}}(t)=-\frac{v^*(t)}{\sqrt{D(t)}}.
```

The stored excitation accounts for the part of the pulse that has entered the delay line but has not yet left it. In interferometric networks one may introduce a delay cavity for each path; only the relative delays normally affect the interference. This finite-mode representation avoids a spatial discretization of the propagating field [Christiansen2026](@cite). The corresponding constructors are described in [Pulse modes](@ref).
